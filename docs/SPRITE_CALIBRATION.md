# 小人大小与落地校准 · 0.18.0

当前操作已由 [0.18.1 固定素体对照](FIXED_SPRITE_REFERENCE.md) 替换：参照固定，只调整图片大小与落地，不再定位头顶。下文保留 0.18.0 的实现与交付记录。

这是服装工作室的前两阶段：完成隔离复用试验，提供真实脚底、身高与房间试穿。分层衣服、母版素体和直接绘画仍按 [流程表](OUTFIT_WORKSHOP_PLAN.md) 后续阶段推进。

## 使用

世界 → 右上头像 → 人物 → 选择人物 → 编辑皮肤 → 站立行走。点选一格并上传单张透明 PNG，或使用已有图集。

打开“大小与落地 · 房间试穿”，点“定位脚底”，再在姿势预览里点实际接地处；点“定位头顶”，再点人物头顶。绿色中心线、地面线、头顶线和半透明轮廓用于对照。轮廓是测量参考，不是已经做好的可穿素体。

图片内留白不再决定人物的实际显示身高。房间中的大小以推荐比例 100% 为基准，可以调整为 30%–175%；房间试穿使用世界相同的绘制函数。校准属于这一组图集，四方向与动作帧共用基准，不逐帧重新裁紧放大。不同原图留白需要选中对应格，使用“拖动这一格”或原有数值控件对齐。

1/2/4 倍按钮只改变编辑视图，不改变人物大小；双指可缩放和平移，一次单指拖动松手后更新一格，取消手势不保存。触屏使用系统文件选择器；未上传单格原图的整图可直接定位脚底和头顶，需要逐格拖动时先上传/替换该格。

原图、缩放和偏移继续保留。按固定底栏“保存修改”才保存到人物形象；未保存返回仍提示。恢复原来的显示比例会移除该图集的校准参数，保留图片和单格编辑，不清空其他皮肤。旧皮肤未校准时保留旧绘制方式。

## 模块与保存

- `sprite-calibration` 拥有归一化坐标、脚底/身高校验、绘制投影和测量轮廓；不读写业务存储，也不识别图片中的身体或脚。
- `character-calibration-ui` 处理指针、视图缩放、模式和房间预览。单格修改交回原 atlas 编辑器，UI 不直接修改 LocalService 数据。
- `CharacterLooksModule.validateAtlas` 接受可选的 `calibration`：版本 1、脚底 x/y、有效身体高度和世界显示比例；拒绝未知字段、非有限值和越界值。脚底/身高按图集帧像素定位，同组使用同一标尺。
- `world-art.drawActor` 将已保存脚底投影到原世界地面坐标，以有效身体高度计算缩放；`previewRoom` 共用此绘制入口。行走帧、朝向、碰撞、人物身份、模型与记忆规则不变。
- 继续使用原形象 PATCH、事务、SQLite 图片去重和 CAS。校准是图集内的小型数据，不另开文件或数据库；旧原图和单格参数仍随备份保存。后台读取同一图集数据，不运行编辑器或 Canvas。

保存后 UI 会重新绑定最新草稿，避免继续拖动时引用上一次保存前的图集。迟到图片、关闭页面和切人物继续走原归属保护；校准预览失效后不接受异步回写。

## 实际复用

本阶段产品继续复用 `character-frame-editor` 的单格原图/合成、原衣橱与图片选择器、世界运动和 `drawActor`。真实接地点和尺度校准需要适配现有投影，Cropper 的选区功能不能替代这些业务参数，因此未引入新裁图应用或第二套状态管理。

`tests/outfit-reuse-probe.mjs` 对固定来源做隔离实验：Piskel `PixelUtils` 的连通填色配小型整数 Frame 适配，LPC `drawFrameToFrame` 抽取后用既有 esbuild 转译。两者在断网浏览器和 Android 11 / WebView 83 中验证边界、同色空操作和实际 Canvas 复制。算法保留为下一阶段绘图/组合的候选，未进入产品运行代码。未复制其他外部算法、样例人物或私人截图。固定版本、SHA-256、Git blob、许可和检查范围见 [来源清单](../config/outfit-workshop-sources.json)。

准备一次忽略目录内的审阅源文件后，可重复离线试验：

```text
node tests/outfit-reuse-probe.mjs --fetch
node tests/outfit-reuse-probe.mjs
```

获取失败或来源哈希不同会终止；源码缓存不进入 APK。`--fetch` 仅访问固定来源，不调用模型。

## 验证入口与范围

- `sprite-calibration.test.mjs`：不同透明边距落在同一点、身体高度一致、旧显示回退、范围校验、保存失败回滚、备份与重启。
- `sprite-calibration-browser.mjs`：实际点脚底/头顶、房间像素、原图保留、尺寸滑条、单格拖动/取消、放大、双指操作不改校准和重启。
- `sprite-calibration-android.mjs`：专用合成模拟器，原生触屏、原生截图、真实 SQLite、进程重启、原签名 code25→26 数据/加密凭据指纹比较，以及离线复用试验。先 `--capture` 在旧版保存指纹，再覆盖安装后运行。
- 原单格上传、衣橱、图片档案浏览器回归继续检查原图恢复、异步归属、动作上传、表情、失败重试及固定返回。旧单格测试改为等待动作编辑区显示后选择文件，避免向仍隐藏的文件输入发送测试事件。

本轮使用合成图片和存档，未调用付费模型。实体手机、真实模型服务，以及后续分层衣服和绘画尚未验证。
