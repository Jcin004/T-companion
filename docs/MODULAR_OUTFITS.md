# 可编辑本体与分部件衣柜（0.20.0 首版）

世界右上角用户菜单的「衣柜」独立于桌面的界面主题「外观」。选人物，再选本体、头发、帽子、配饰、上衣、下装或鞋子。创建透明素材，上传该方向的站立图，或点「绘制 / 修改」进入原方格绘画台。保存后随时可以再次编辑。整套旧皮肤、表情与物品动作保留在「人物」。

本体使用 Jcin004 提供并确认允许公开随包分发的原图；正面从原图读取，去除边缘连通的白色背景，保留衣服内部白色。侧面和背面为 AI 辅助试稿，来源见 `frontend/assets/body/PROVENANCE.md`，不是由正面镜像冒充的背面。所有方向都可以上传替换或重画。64×96 画布，标准身高 80 像素，固定脚底 (32,88)；衣柜身高可在 56～80 像素试调。

先「选为本体」，再穿上各部件。重复点击已穿部件为「脱下」。衣物大小、左右和上下数值仅属于这个穿戴者，原始素材不改变。没有使用滚轮调节的滑块；数字框收到滚轮时让出焦点，滚轮继续滚页面。关闭和应用固定在窗口两端。

上传按所选类别放入模板区域，转为可编辑的 16 色像素。应使用单张透明 PNG；原图片任意裁切和全色绘图不是本版能力。绘画台的半透明本体只作参照，不会混入衣物像素。人物本体也直接绘制在自己的独立透明层。共享素材修改影响所有引用者；需要独立款式时先复制。正在引用的素材不能删除。

## 模块与保存

- `outfit-catalog.js`：素材、归属引用、穿搭和版本校验；`/character-looks/user/workshop` GET/PUT。原形象模块调用，统一事务保存 `outfit_catalog`，没有第二个业务数据库。
- `outfit-motion.js`：共享六部位坐标、身高适配和站立→A→站立→B 顺序；无 DOM、存储或人物身份。
- `outfit-image.js`：图片导入与像素投影缓存；可编辑索引像素为底账，Canvas 可丢弃重建。
- `outfit-compose.js`：按身体和衣服共用的姿态绘制；衣柜与独立验证页调用同一入口。
- `outfit-wardrobe-ui.js`：分类选择和试穿；复用 `clothing-workbench-ui.js`、`PaintSession` 和已有 Piskel 填色适配。仅通过形象 API 写入。

每件素材只有一个稳定 ID、模板 ID、工程和版本，可有未应用的草稿。每个人物只存本体引用、身高和各部件的引用/适配数值。备份沿用原文档，旧备份没有此字段仍然有效。整目录 CAS 加原 SQLite 写入租约防止前后台并发覆盖；重试相同内容不递增版本；失败不替换内存中的成功版本。无界面宿主能校验和保存这些数据，不依赖 Canvas。

「应用到世界」检查当前版本与四方向完整性，在原形象事务中更新独立的「分层穿搭」皮肤并选中；不覆盖其他旧皮肤。合成 PNG 是派生显示结果，可由素材与穿搭重建。修改素材或试穿后，需要再次明确应用，世界不会自行变装。新增皮肤默认不开放 AI。

## 动作适配的当前边界

首版验证同一件上衣在两个身高上的站立、迈步及独立穿戴偏移。站立素材按固定部位模板移动；有独立绘制的迈步时优先使用它。改变站立图会同步仍跟随站立的默认姿势，不覆盖已单独绘制的姿势。原图的肢体位置应接近模板；不是任意图片的自动骨骼绑定。侧面层序、宽袖、长裙和长发的遮挡尚需专用映射，不能视作全部服装均已适配。

浇水、挥手、坐下等动作模板、独立动作库界面、版型蒙版与 AI 组合选衣待后续。当前没有把缺失动作补成已执行事件，也没有调用生图 API 或付费聊天模型做测试。

## 复用与验证

复用原方格画笔、笔画撤销、Piskel 连通填色、SQLite 事务、备份和世界行走图集接口。沿用既有固定版本研究清单 `config/outfit-workshop-sources.json`：LPC 的部件/帧索引、FashionSense 的体型/偏移及 Outfit Studio 的试穿/应用分离只作设计参考，没有导入新的第三方代码或游戏贴图。LPC 渲染器仍依赖其目录、状态与 Mithril；SMAPI/C# 模块不能在现有 Canvas/Android 执行，因此适配小型坐标映射，没有嵌入另一套引擎。

Node 检查覆盖共享引用、两个身高、脚底、版本冲突、重复重试、保存失败、草稿重启、备份、非法归属/穿戴与世界应用。浏览器测试 `tests/outfit-wardrobe-browser.mjs` 使用合成数据验证实际触屏绘画、保存、重启和继续编辑；`outfit-fit-lab.html` 是共享生产导入/渲染入口的正面适配验证页。原绘画台回归通过。Android 11 / WebView 83 专用模拟器已通过原生触屏本体绘画、应用到世界、原生房间/衣柜截图、SQLite 重启，以及原签名 30→31 覆盖安装的业务数据和凭据指纹比较；测试后恢复原合成存档。曾发现不支持的逻辑赋值语法导致启动失败，已改兼容写法；新建素材 ID 也兼容没有 randomUUID 的 WebView，并有浏览器回归。没有实体手机或真实模型服务验证。154 项 Node、103 项 Python 通过。
