# 本机记忆网召回（0.8.0）

适用于 Android 独立本机模式与本机网页；可选 Python 共同后端没有接入这条新管线。人物、消息、记忆、标签和关系仍由原领域及事务接口保存，召回是只读查询，不修改原文、关系方向、名册或人物知情范围。

## 数据流

`LocalService.stream` 或 `/contacts/:id/context-preview` → 同一 `recallPlan` → `memoryContext` → `buildContext` → 原模型传输；实际日志记录这份计划，不另外计算。`recall()` 保留数组返回形式，旧调用路径和证据函数导出不变。

1. 当前消息先查原有 Serein 衍生 BM25（标题、正文、来源原话），只纳入当前人物已启用且证据有效的记忆。
2. Serein 线索适配器识别“那个、那件、上次、继续”等指代/延续信号，只在需要时额外查询当前会话最近 0–4 条已完成用户消息；默认两条，历史范围为 0 时不读取近期线索。重试限制在原用户消息之前；不使用失败轮次、助手续写或其他会话来补线索。这是有界启发式，不是完整语义指代消解。
3. 人工保存且名册快照仍匹配的核心标签可参与匹配；明确的自我提问可取回最多两项。模型生成但未人工保存的标签不参与；标签是解读而非 Canon。没有实现自动人格成长。
4. 初始候选最多六个作为种子，只读取一跳已复核关联，最多新增两个记忆邻居、两个标签邻居。读入边可找到依据，但输出仍是原 from → to，不写回反向关系。扩展候选排序不高于其种子，种子未选中时不携带该邻居。不会沿新邻居再走一跳，也不跨人物知情范围。
5. 按相关性选择，记忆与标签共用条数上限；完整 JSON 材料（含原话、关联说明）共用字符预算。关联仅在两端都被选中时注入。矛盾材料不合并，相关条目标记另有矛盾依据；对未完整携带的材料不推断当前事实。过期关系、暂停或无效证据节点立即退出。
6. 返回召回回执：线索消息 ID、候选来源、是否被预算/条数排除、过期原因和实际材料大小。回执不存原始查询、来源原文或标签正文；正文仅在用户启用的上下文捕获中出现。既有日志仍有其脱敏和容量限制。

## 设置与界面

记忆 → 召回与整理设置：保留原总开关、条数、字符预算和专用连接；新增近期用户线索条数、关联扩展开关、人工标签开关。新字段是 memory.version=1 的向后兼容补充，旧备份由既有验证器填默认值；回滚旧版本不会删除新字段或原记录。

日志 App → 当前上下文预览或展开实际请求 → 本轮记忆召回。预览没有模型调用、不读取凭据、不保存草稿或召回次数；新设置与其他写入共用原事务队列。

每日总结仍保留日历查看、编辑和重写，本轮没有把摘要无条件塞入上下文，也没有新增向量库、embedding 服务、重排网络请求、AI 关系候选或自动人格改写。原词法检索的改述匹配限制仍存在。

## 文件边界与复用

- memory-evidence.js：原 memory-core.js 中的来源、日期与名册证据投影迁移；兼容导出保留。
- memory-recall.js：只读候选、有限关系扩展、预算与模型材料；不包含 DOM、持久化或网络。
- recall-cues.js：Serein retrieval_budget.py 的 MIT 适配，版本/文件/blob/作者/改动及完整许可见 THIRD_PARTY_NOTICES.md 和现有 Serein-MIT.txt。
- memory-core.js：保留文档验证与兼容调用；local-queries.js、local-service.js 共用召回计划；memory-ui.js 和 diagnostics.js 通过原接口展示设置和回执。

验证覆盖：人物/会话隔离、来源核对、单跳与环、方向不变、人工标签与失效、矛盾、共享预算与总开关、旧备份、事务失败、预览与实际一致；浏览器验证设置持久化和日志显示。默认模拟模型，不调用付费服务。
