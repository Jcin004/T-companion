# 绘画导航与半格细节（0.20.2）

电脑：左键绘画，滚轮以鼠标所在位置为中心缩放，按住右键拖动画布。中键不画图，也不启动浏览器自动滚屏。滚轮只在画布内接管，其他区域继续滚页面。缩放或平移不会保存为笔迹。

手机：单指绘画；双指缩放和平移。第二根手指加入时取消尚未完成的笔画，抬起其中一指后也不会立即继续画，避免手势结束留下点。也保留「移动画布」工具和放大/缩小按钮，便于单手操作。关闭与保存仍固定可见。

「1 像素」是实际绘画格子，不是屏幕像素。旧画作使用 64×96；点「细化画格（128×192）」后，每个原格无损分成四格，一格的边长相当于原来的半格。选择 1 像素笔格即可画更细的线，放大画布则方便点准。细化可以撤销/重做；不会自动改变未编辑的旧作品。

细化同时转换四方向、三姿势的坐标精度，各帧仍独立绘画，已有图案按最近邻保留。已有素材、身体比例、脚底和房间显示大小不变；不会把高精度图在保存或合成时压回 64×96。半格也经过混合精度的本体/衣物合成验证。

## 接口与数据

复用现有 PaintSession、Piskel 填色、绘画工程、人物形象 API、衣柜和统一 SQLite 事务。绘画工程可选 `pixel_scale:2`，缺省仍为 1；模板版本及业务文档版本不变。原 API、旧备份继续可读，含精细工程的备份需要本版及以后版本读取。

`clothing-project.js` 校验和转换尺寸；`pixel-paint.js` 使用工程尺寸绘画、填色、镜像、撤销；`clothing-workbench-ui.js` 管理鼠标/触屏视图与操作取消；`clothing-render.js`、`outfit-image.js`、`outfit-compose.js` 保留真实分辨率。衣柜只传入对应素材的像素精度，模型、人物身份和记忆均不参与绘画。

没有引入新的绘图引擎、依赖或第三方文件；继续复用已审计的 Piskel 填色包装。视图缩放限制在 0.25～32 倍，不改变画笔单位；细化只增加一档，避免界面重复堆叠设置。

- `paint-resolution.test.mjs`：全部姿势的原格无损转换、半格独立绘画/镜像/填色、撤销重做、无效尺寸拒绝。
- `paint-navigation-browser.mjs`：真实鼠标滚轮、右键和中键；CDP 多点触摸手势取消；精细笔迹、384×768 图集、相同脚底/世界比例、混合精度衣物细线，以及备份和页面重启。
