## 数据与性能

- 模型结果先按原始 JSON 解析，再提取对象，最后尝试语法修复。数组、多对象、超限结果、缺失尾部均拒绝；不执行返回文本。格式修复后照常核验每段来源原话。
- 记忆整理、每日总结、自我分析共用新解析入口，日志记录 raw/wrapped/repaired 模式。解析修复不增加模型调用；不会自动补写人物事实。
- 词索引按人物隔离、按内容签名缓存；编辑、暂停、删除和导入后会失效重建。索引可重建，不改变原始聊天和记忆正文。
- 来源核验共用一次构建的消息查找表，日总结来源也按人物/日期分组，避免逐条记忆反复扫描完整聊天。
- 隔离合成材料：1000 条记忆、2000 条消息，同机单次校验从约 205 ms 到约 2 ms；来源引文中的唯一关键词可正确召回对应记忆。这是局部性能记录，不代表真实手机整体响应速度。
- 原有备份结构兼容，不迁移或删除角色、消息和凭据。召回预算仍以字符计。
