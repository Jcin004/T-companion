# 单格小人图片 · 0.16.0

世界 → 右上头像 → 人物 → 编辑皮肤 → 站立行走。先点选朝向和姿势，再按“上传／替换这一格”选择单张透明 PNG。上传只更新选中的格子，其他格子保留原图；没有自定义图集时先从对应人物的备用小人生成基础图集。物品动作和自定义小人姿态共用这个编辑入口。

主页面保留一张帧表和一个播放预览，原重复四帧展示已移除。整图导入、不同排列、方向行、站立帧与播放顺序收到“整张图集导入与高级设置”，原三帧、四帧和自定义图集继续读取。整图替换或重新切片会提示清除单格编辑记录；原普通保存、固定返回／关闭／保存及未保存提示继续使用。

## 尺寸与对齐

无需强制 48×48。已有图集保留其单格尺寸，新图集以首张图片画布确定长宽，最长边最多 128 像素，保持比例。第一张图确定整套的基础像素缩放，后续单图沿用同一缩放；不会把每帧各自裁紧并放大铺满。源图大小不同可能被裁到格子边界，需在预览中调整，建议同一套原图使用一致画布。

单图按原画布居中、底部对齐。上传后可以调整这一格的大小、左右和上下像素位置；绿色基准线表示中心和画布底部，迈腿帧叠加同朝向已上传站立帧的半透明对照。不会自动把透明留白识别成人物或重新画缺失动作。缩放关闭平滑插值，像素素材尽量使用整数倍；“重置对齐”恢复共同缩放和零偏移，“还原这一格”恢复编辑前原图。保存后仍保留原单张图片，可继续调整，原图超出格子的部分不会被永久裁掉。

## 模块与数据

- CharacterLooksModule 仍拥有人物／皮肤资源验证与原 PATCH 写入，经 LocalService 统一事务和 SQLite 保存。新增 atlas.frame_editor 可选字段，旧数据无需迁移；包括基础图、画布、共用缩放和已替换格子的原图／缩放／位置。
- character-frame-editor 只负责排列、合成和对齐参照，不读取业务存储。atlas.image 是从基础图和单格原图生成的兼容图集，原世界渲染和后台规则继续读取它，无需在 QuickJS 中运行 Canvas。基础图与原单张图保留，合成结果可重建。
- character-atlas-ui 管选格、草稿、异步任务和预览。迟到结果绑定原人物／皮肤／格子，取消或切换后不附到新对象；图片处理中禁用保存按钮，避免提前保存。原图与合成图作为同一皮肤原子保存，失败保留草稿和原业务文档。
- TLookAssets 对默认及额外皮肤的行走、交互和姿态图集遍历基础图和单格源图，沿用 SQLite 内容哈希图片行、恢复与垃圾回收；图片数据不膨胀到单个业务文档 CursorWindow 行。备份包含完整源图和参数。
- character-image-input 统一浏览器文件与 Android 图片选择。Android 复用 TDevice.importFile({image:true}) 的系统 OPEN_DOCUMENT 回调，按图片尺寸、格式和字节上限检查；原不带 image 参数的 JSON 备份读取语义保留。取消不显示错误，前后台切换不丢掉仍归属当前人物／格子的选图结果，无额外存储权限。

本轮不改变世界行动、角色身份、模型配置、记忆或移动规则。本机网页及独立 Android 使用同一形象接口，共同后端未新增资源管理。图片不发送给模型；没有生成式裁图、补帧或新引擎依赖。

## 复用与来源

复用已有 character-looks、character-atlas-ui、world-art.previewSprite、TLookAssets 与 TDevice 文档选择适配。只增加图像合成及平台文件输入的职责接口；参考资料见 config/single-frame-sources.json。Godot 官方文档说明独立图片与图集均可作为动画帧，Unity 文档说明定位基准点；只参考交互和坐标概念，没有导入源代码、人物或素材。用户截图不进入公开源码或附件。

## 验证入口

character-frame-editor.test.mjs 覆盖居中／脚底定位、方向映射、参数验证、事务失败、备份和原生输入迟到结果／取消。single-frame-browser.mjs 用透明合成 PNG 检查选格替换、共同缩放、像素位置、保留其他格子、原图重编辑、保存失败重试、人物隔离、动作帧、重启，以及世界 Canvas 实际使用合成图片。原衣橱、整图、世界对话／历史／记忆、移动与聊天设置回归继续执行。

single-frame-android.mjs 在专用 Android 11 / WebView 83 模拟器使用原生触屏打开编辑器和系统选图；DocumentsUI 文件列表点击不能稳定打开文件，测试用原生键盘焦点选中准确文件名并确认，未注入文件 URI 或伪造插件返回。返回 PNG 字节与测试文件逐字节相同，完成单格保存和真实进程重启。原生 SQLite 大图片、单格源图恢复、CAS 和失败回滚由 WorldVisualInstrumentation 验证。原 JSON 备份文档选择和图片取消也已通过；取消没有修改业务文档。实际发布与最终版本验收在交付后补记；实体手机未验证。
