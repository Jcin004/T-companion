# 执行路线（2026-10-18）

当前成果、平台差异以 CURRENT_ARCHITECTURE.md 为准；已有行为的回归入口见 FEATURE_BASELINE.md。早期 Phase 1.5 的阶段标记不再表示当前进度。

## 已有基础

已合入：本机事务保存修复、独立只读查询、来源记忆及每日总结、自我标签、有向记忆关联与标签依据。角色名册、模型连接分组、聊天风格、外观、日志与独立 Android 聊天保留。没有实现自主生活或跨设备自动同步。

## 当前收尾阶段

0.7.0 已发布；0.7.1～0.8.0 的动作模板、悬浮切换、更新渠道及记忆召回位于开发 PR。0.8.1 在这些成果上修复上下文输入、子设置返回并分离设置界面职责。分支提交不表示已合并或已发布。

1. 修复全局/当前聊天上下文输入与返回层级，验证旧功能和数据保留。
2. 整理模块职责、当前文档和 PR 依赖；采用同包名、同签名覆盖安装。
3. 审核后整合发布 APK、匹配源码和更新清单。GitHub 可达性与免 VPN 托管单独处理，不能靠客户端改动承诺网络可达。

## 随后执行顺序

4. 让已确认、已复核的记忆关联有限参与聊天，限制人物范围、扩展深度和材料预算，并记录实际注入。
5. AI 关联候选：提出证据，用户确认后生效，不覆盖人工关系。
6. 记忆网视图：人物 → 核心标签 → 解读 → 事件 → 原话；复用同一关系数据。
7. 自我认知与成长：固定身份、稳定倾向、当前状态、成长候选分开，可校正和撤销。
8. 像素世界规划：群像相关的多人事件、群聊、人物关系和世界运行统一纳入该领域；参与者、各自理解与知情范围分别建模。
9. 像素世界实现：地图、位置、见面互动、共同事件和群聊；人物身份及个人记忆仍由原模块拥有，世界通过明确接口读取。
10. 生活状态、欲望与自主唤醒：在像素世界之后实现作息、目标和行动，明确宿主、去重、取消与打扰规则。
11. 桌面小人与设备感知：通过明确接口获取允许的观察，屏幕、摄像头、定位分别控制。
12. 剧情空间与冒险：与日常事实分区，明确哪些共同经历可写回。

## 每阶段交付

先检查架构适配、现有模块和参考仓库许可；按范围开发、回归测试、提交、推送并创建 PR。合并和发布采用当次用户授权，不默认自动合并。不为了未来功能提前堆空模块；不把测试替身或模拟器验收写成真实模型与实体手机验收。
