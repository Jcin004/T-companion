# 0.4.0：外观、连接库与聊天表达

## 使用方式

- 桌面新增「外观」App。主题、字号从设置迁出；可选择三套原创渐变壁纸或自选 PNG/JPEG/WebP，调整图标样式、设备字体、气泡颜色和圆角、轻量动效。系统要求减少动态时不播放动效。
- 设置中的「模型连接库」可建立、编辑、删除连接，创建、重命名或移除单层分组，在编辑连接时选择所属分组。移除分组不删除连接。聊天标题栏的双箭头可直接切换已保存连接。
- 原单连接迁为「原有连接」，保留原密钥。Android 每个连接使用独立的 Keystore 加密密文；浏览器密钥仍在该站点 localStorage，保护弱于 Android。模型支持范围仍为 OpenAI Chat Completions 文字 SSE。
- 聊天详情新增「聊天风格与动作组」，可开关空行分条和动作描写，调整动作、emoji、语音条的倾向。输入区有动作描写快捷开关。
- 动态模式把倾向、人设和情景一起交给模型，不承诺实际出现次数。概率模式按请求标识选择本轮候选类型，重试不重新抽取。0 关闭；获准也不强制使用。每轮最多一条格式化语音条。
- 模型用空行分消息，用 `[动作:…]`、`[表情:…]`、`[语音:…]` 标注表达。显示层解析，所有文字按文本渲染；动作组不会执行外部工具。关闭的格式化动作/表情不显示，关闭语音时保留文字。普通文本中的自然语言动作和 emoji 由模型遵循提示词，不能保证任意模型都严格服从。
- 语音条是设备 TTS，点击才朗读，不是已生成的录音文件或云端克隆声音。图片表情包、转账、设备操作和朋友圈不在本次实现范围。

## 数据与模式

本次新增的连接库、分组及聊天风格用于默认本机模式；可选共同后端继续使用原单连接接口，不冒充自动同步。外观保存在当前设备的本机数据中。备份包含连接元数据、分组、外观与聊天设置，不含密钥；恢复时只有匹配连接标识和相同服务域名才保留该设备已有密钥，其他连接需要重新填写。更改连接的服务域名时须重新输入或明确清除密钥。

分条是显示与生成格式：同一生成轮次保存完整原文及所用表达设置，刷新后重新投影，不为每个气泡重复保存上下文。历史按原消息标识搜索与跳转。显示主题变化不会改写角色身份。

## 参考与实现来源

- float `lib/rich-message-parser.ts`：参考空行分段、表达标记分离的思路；本次表达模块独立实现，未复制其解析器。
- float `lib/action-parser.ts`、`lib/chat-engine.ts`：区分表达与带副作用的动作分发，本次只提供表达。
- float `lib/settings-types.ts`、`components/settings/api-settings.tsx`：参考多连接标识与选择结构；单层文件夹分组按本项目需求实现。
- SullyOS `utils/messageFormat.ts`、`utils/assistantActionFormat.ts`：参考不同消息类型使用统一格式处理；没有复制其源码。
- 原有 SSE JSON 解析的 float 来源及 AGPL 条件保持原记录。

React 不是本次改动的前提。沿用原生 HTML/CSS/JS 和 Capacitor，将新表达、连接元数据、配置界面分别放在小模块中。

## 验证入口

- `node --test tests/*.test.mjs`：迁移、密钥隔离、备份校验、域名变更、表达解析、确定性候选与状态恢复。
- `node tests/desktop.mjs`：原桌面、历史浏览和聊天回归。
- `node tests/preferences-browser.mjs`：独立 Playwright 上下文与模拟模型，覆盖外观迁出、分组与切换、动作/emoji/语音、刷新和备份；不调用用户真实密钥。

APK 版本递增为 0.4.0-trial / versionCode 4，沿用原包名及本机试用签名。应用内在线下载安装更新仍未接入。

## 本次结果

- 13 项 Node 测试、85 项 Python 测试通过；原浏览器桌面/600 条历史流程以及新增配置流程通过。
- 新增浏览器验收使用模拟模型，验证两条连接的请求分别携带各自的测试密钥；分条、动作、emoji、语音条、关闭控制、刷新与无密钥备份均通过。
- Android 11 / API 30 隔离模拟器安装 0.3.0 后，以固定测试数据建立旧库，再覆盖安装同签名 0.4.0。原角色、两条消息、模型配置和字号保留；旧单连接迁移为「原有连接」。
- 通过 Android 界面分别保存两条测试密钥，确认独立加密条目、SQLite 不含明文测试密钥、日志不含测试密钥；重启后两个连接元数据保留。未进行物理手机或真实模型服务商验证。
- APK 签名 v1/v2/v3、包名、versionCode 4 和 zipalign 检查通过。
- 本机构建使用 Java 21、Gradle 8.11.1、Android 35 平台。任务为 `:app:assembleDebug`；本机使用 Android 34 已安装的 aapt2 通过 `android.aapt2FromMavenOverride` 指定资源工具，避免额外的 Maven 工具下载。未更改项目的 compileSdk/targetSdk 35。

产物位于忽略目录 `artifacts/`：`T-companion-0.4.0-trial.apk`、对应源码及试用分发包。保留原 0.3 安装包，不发布公开 Release。
