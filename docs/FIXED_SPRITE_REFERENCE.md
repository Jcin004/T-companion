# 固定素体对照 · 0.18.1

0.18.0 的头顶/脚底定位把测量与参照混在一起。现在参照不动，只移动或缩放上传的人物图片；取消“定位头顶”和“定位脚底”。本机网页和 Android 使用同一界面与绘制规则。

## 标准与使用

| 项目 | 固定标准 |
|---|---|
| 新母版画布 | 64×96 像素 |
| 素体高度 | 80 像素，头顶 y=8，脚底 y=88 |
| 脚底中心 | x=32、y=88，距底边 8 像素 |
| 身体轮廓 | 用户确认的素体预览，手工描为半透明几何轮廓 |
| 房间显示 | 标准素体高为房间画面宽度的 20%，随整个画面等比适配 |

世界 → 右上头像 → 人物 → 编辑皮肤 → 站立行走 → “对照素体 · 调整大小与落地”。选格上传单张 PNG 后，拖动预览中的图片，把脚放到固定地面上；用“人物大小”对照固定素体缩放。头发和帽子允许超过标准头顶线。标准约束新母版；旧素材可保留原分辨率和透明边距，通过缩放与位置适配，不强制重采样成 64×96。

大小与落地对这一组图集生效，四方向共用；单格偏移/大小和单格拖动收进“高级：微调这一帧”，用于修正某张姿势。站立叠影可帮助修正迈步，参照轮廓仍固定。行走播放与停止都使用同一投影，不切回另一种全帧铺满方式。

“放大查看”的原大、放大、细看只改变编辑视口，也支持双指缩放和平移，不改变保存比例。鼠标滚轮经过大小滑条或位置数字框时继续滑动页面，不修改数值；主动拖滑条、使用方向键或编辑数字仍有效。高级区关闭后恢复整组拖动。

房间试穿左侧为固定标准素体，右侧为当前人物，两者站在同一地面高度；关闭“显示固定素体与基准线”可单独看人物。编辑器和房间使用同一标准高度。固定返回、关闭和保存沿用衣橱弹窗；只有按“保存修改”才写入业务存档，原图不被覆盖。恢复原来比例移除本组校准，保留原图和单格编辑。

## 模块和兼容

- `sprite-reference.js`：固定标准和参考轮廓，不含人物身份、图片存储或世界状态。轮廓依据用户指定的已认可预览手工描述，只打包几何点，不打包私人图片。
- `sprite-calibration.js`：沿用版本 1 校准，负责固定视图投影、整组位置与缩放换算。旧 `body_height` 和 `world_height` 继续以比值决定缩放，平移时保持该比值；无需用户再测头顶。保留旧版校准读取和校验。
- `character-calibration-ui`：手势、固定参照开关、大小、房间预览和滚轮处理；所有修改交回原 atlas 草稿入口。
- `character-frame-editor`：保留原图、单格合成和原始偏移；主预览改用与房间相同的缩放关系。
- `world-art`：复用真实房间/人物绘制；仅试穿显示参考素体。已校准人物的名字放在图像上方，阴影跟随可见投影尺度，避免校准比例换算后文字压在人身上。

继续使用原衣橱、人物 ID、形象 PATCH、SQLite 图片去重、统一事务和备份；无数据库迁移。未编辑旧皮肤保持原来的显示。人物、模型、聊天、记忆、居民调度没有新数据或修改入口。本次复用现有实现，不引入第三方运行代码、依赖或图像编辑服务。

固定轮廓是校准参照，尚不是可穿的分层素体。四方向母版、服装版型、直接绘画继续按 [流程表](OUTFIT_WORKSHOP_PLAN.md) 开发。
