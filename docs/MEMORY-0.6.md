# 0.6.0：来源记忆与自我

本机网页和 Android 共用记忆逻辑；Android 沿用原生 SQLite、Keystore 与模型传输。共同后端尚无这些记忆接口，选择该模式时入口会说明范围，不会混入本机记忆。当前仓库、源码包及 APK 保持私有，不发布公开更新源。包名与签名沿用原版，versionCode 7，覆盖安装保留数据。

## 使用

1. 先在名册创建角色，在设置配置模型，完成至少一轮聊天。
2. 桌面 → 记忆 → 选择人物。可手动选取来源原话保存，或点“整理新消息”。按日期整理需要先选日期。手工保存不调用模型。
3. 记忆正文与来源原话分开保存。点击原话跳至实际聊天；编辑保留最近十个旧版本。暂停阻止召回；删除记忆保留聊天。关联其他人物只表示事件涉及谁，不表示对方知道这件事，反向关系不会自动生成。
4. “召回与整理设置”控制开关、每次最多 1–12 条、500–12000 字符材料预算；默认开启召回，4 条、4000 字符。它独立于原文历史条数；原文历史为 0 仍可召回。日志保留实际发送内容与召回记忆 ID。
5. 整理模型连接可跟随当前聊天连接，或选择已保存的专用连接；选用专用连接不会切换聊天模型，不复制密钥。整理、自我分析和每日总结会额外调用模型。
6. 自动整理默认关闭。开启后，应用运行时，在聊天完成后按累计完成消息条数触发。默认 20，可设 4–200；一轮用户与角色各算一条。每次最多整理 80 条，较多历史可多次手动整理。它不是 Android 后台保活或定时唤醒。聊天优先，可以取消正在进行的模型整理。
7. 聊天详情 → 聊天记录 → 日历：日期数字仍跳到当天消息，独立总结标记打开卡片。已有卡片悬浮显示内容，手机点击打开。可编辑、删除、按当天原始消息重写、查看最近十个旧版本。删除卡片及其版本保留来源消息。总结用于回顾，不自动当成长程记忆注入聊天。
8. 桌面 → 自我：从名册分析，或手动添加核心标签。标签含解读、名册连续原文、明确描述/推测标记，支持编辑、删除和版本记录。重新分析保留人工标签；同名 AI 标签保留旧版，未再次提取的旧 AI 标签会移除。名册变化会提示旧标签需要复核。当前标签用于校对名册解读，不自动改写聊天身份。
9. 设置 → 导出备份包含记忆、来源消息、总结、核心标签与设置，不含模型密钥。旧备份可导入并创建空记忆库；带记忆的备份会核查来源引用。

## 实现和界限

- `memory-core.js` 负责数据规则、原话核验、按时区定位当天消息及关键词召回。`memory-service.js` 隐藏整理、总结、分析、版本和保存逻辑；`memory-ui.js` 提供两个独立 App 与日历卡片。
- 数据仍在现有文档中，增加 `memory.version = 1`，无需新建图数据库或外部服务。事件含 owner、关联人物、性质、来源 ID/逐字引用、状态与版本。读写按 owner 隔离，只有完整轮次可作来源。单向关联不会自动共享知识。
- 模型候选全部校验后才写入；虚构引文、跨角色引文、未完成消息不会通过。模型整理结果去重，成功保存后才推进进度；存储失败回滚记忆和进度。后完成的旧消息重试仍可纳入整理。
- 每日总结重新读取记录时区当天的完整原始消息；超过 300 条或材料上限时提示分段，不偷偷截断。日整理超过 100 条会提示缩小范围。编辑窗口列最近 300 条来源，旧记忆已有来源仍保留。整理输出不是事实保证，仍需人工复核含义。
- 召回使用中文双字关键词和英文词匹配，按相关分数、更新时间排序，并受条数与字符预算限制。没有向量或混合检索，不按新近度硬填无关记忆。注入内容带原话说话者、时间和来源 ID，标记为历史数据，不能成为指令或覆盖 Canon。
- 完整认知网、核心标签与事件的可视化连线、主观关系边、矛盾处理、自动成长和自主生活仍属后续。当前圆圈为核心标签入口，不是完整图谱。
- 本轮模块原创实现；设计参考既有调研记录，没有新增复制外部项目代码或资产。既有 float SSE 解析和 Capacitor 许可记录保持有效。

## 验证

- `node --test tests/*.test.mjs`：25 项通过，包含来源、角色隔离、停用、实际上下文、失败回滚、整理进度、重试、模型分流、备份、自我人工保护、每日总结版本和取消。
- Python：86 项通过。
- 浏览器：`memory-browser.mjs` 实测整理、来源跳转、实际召回、角色隔离、自我分析与人工保护、日历卡片编辑/重写/旧版/删除、重载持久、暂停召回。历史条数、日志、外观/模型分组/聊天风格流程继续通过。
- Android 11 / WebView 83：原签名覆盖安装 0.6.0 成功；原角色、消息、配置、草稿和模型连接保持。`memory-android.mjs` 经 WebView CDP，在真实原生 SQLite/Keystore 上运行，注入模拟模型传输以覆盖整理、总结、自我；UI 显示及总结编辑、重载持久通过。测试后恢复模拟器原始数据并清理添加的测试凭据。
- 全部模型测试隔离模拟，不调用付费服务，未作真实手机与真实服务商验收。Android 本轮不重新验收 HTTPS 模型传输；它沿用已有实现。测试曾发现本机 HTTP 会被 Android 网络策略拒绝，最终测试注入模拟传输，没有为测试放宽正式网络策略。

浏览器：构建网页后用本机静态服务器启动 `dist`，运行 `node tests/memory-browser.mjs`（默认端口 8012）。Android 脚本只用于隔离模拟器，需先保存升级前文档至忽略的 `data/backups/memory060-before/state.json`，将目标 WebView 的 CDP 转发至 9223；不用于真实手机。
