# 联系人式聊天试用版

## 数据与职责

- SQLite 是角色、联系人、消息及全局偏好的共同权威来源。首次升级导入原 Canon/Persona；之后通过人设名册编辑。原 YAML 仅作为新安装的种子，不在每次聊天时覆盖数据库。
- 每个角色有独立 ID；发起聊天复用该角色的联系人。历史 MVP 的会话 ID 与消息原样保留，归属初始角色，不删除或合并旧记录。
- 全局模型连接、主题、字体、时区和默认声音只保存在设置中。聊天详情保存备注、背景和角色声音覆盖，并跳转到名册、搜索和日历。
- 草稿、未读阅读位置、后端地址、后端访问口令按设备保存。模型密钥只留在后端，不通过读取配置、备份或消息返回前端。
- `sources/` 不参与构建或迁移，保持只读。

## 消息与流式协议

`POST /api/v1/contacts/{id}/stream` 接收 `message` 和客户端生成的 `request_id`，返回 SSE：`accepted`、多个 `delta`、`complete` 或 `failed`。这是实际模型流，不是把完整响应定时逐字播放。

用户消息在发起生成时持久化。相同请求 ID 和正文重试复用同一条用户消息；已完成的请求直接返回完成状态。相同 ID 配不同正文或会话返回 409。SQLite 部分唯一索引保证每个会话同时只有一个生成请求。

回复完整生成后事务性保存助手消息。失败、超时或断开流会把原请求标为失败，可再次尝试；未完成的草稿回复不作为完成消息进入后续模型上下文。服务重启将遗留生成标为失败。一次生成最长 180 秒、回复上限 100,000 字符。以完整回复和段落保留自然语义，不机械拆句。

上下文保留近期 30 条已完成消息，按角色隔离。原 `BASE_RUNTIME_INVARIANTS` 始终在身份之前，部署附加指令仅追加。聊天和模型输出没有修改角色资料的代码路径。旧 `/api/chat` 和 `/api/sessions` 在生产返回 410，避免旧 YAML / 环境变量路径绕过名册和全局配置；新界面统一使用 `/api/v1`。旧运行时仍保留独立的基础单元测试。

## 历史浏览

消息以单调递增整数 ID 稳定排序，不以时间戳作为唯一游标。打开读取最近 40 条；上滑按 `before` 读取，跳转后可用 `before` 和 `after` 继续浏览。`anchor` 返回目标消息及其前后记录，不限制为某一天。

前端最多保留 160 条消息 DOM。加载旧记录前保存视口内消息及其像素偏移，更新后恢复。移出窗口的上下文仍可再次加载。发送时返回最新记录，避免把新回复插到旧历史视口。

关键词搜索对 `%`、`_` 和反斜杠作字面转义，每次最多 50 条，继续加载使用 ID 游标。日历按已保存 IANA 时区计算 UTC 边界，默认 `Asia/Shanghai`；只查询指定月份，返回有消息日期和当天第一条消息 ID。API 的历史 UTC 时间格式为 `YYYY-MM-DD HH:MM:SS`，前端明确按 UTC 解析，再按用户时区显示。

## 网络与认证

桌面使用 `http://127.0.0.1:8000`；手机使用相同进程的 HTTPS 8443 监听端口。使用单进程启动器，避免两个服务各自恢复生成状态。进程锁防止同一数据库被重复启动器打开。

远程 `/api/*` 请求要求 `Authorization: Bearer <access-token>`。安装生成 `data/access-token.txt`，可由进程环境变量 `T_ACCESS_TOKEN` 覆盖。不得把口令写进 APK、Git 或模型提示词。服务不信任代理转发头；远程部署可在自己的 TLS 反向代理后运行，仍须访问口令。

APK 只接受 HTTPS 后端；禁止明文和混合内容，不忽略证书错误。调试试用包允许用户主动安装的 CA，正式版本仅信任系统 CA。内置页面源为 `https://localhost`，后端仅为该源配置跨域访问。Windows TLS 生成脚本将数据目录 ACL 收紧到当前用户和 SYSTEM。模型密钥由本机文件权限保护；便携备份不含密钥。

专用 Windows 防火墙规则限定本机指定 LAN IP、8443 端口、Python 程序和本地子网。没有修改其他规则、DNS、Worker 或隧道。网络若隔离同一 Wi-Fi 中的设备，需使用自己的受信 HTTPS 域名或允许设备互访的网络。

## 备份与源码

导出 JSON 是事务一致的快照，包含身份、记录、消息状态、备注、声音及全局偏好，排除模型密钥、访问口令和设备草稿。生成时禁止备份或恢复。恢复先验证结构、引用和大小，之后单个事务替换数据；保留本安装现有模型密钥。恢复前在 UI 明确提示替换。

设置提供许可、署名和复用记录，以及对应源码 ZIP。ZIP 按白名单收集程序、测试、构建脚本和许可，排除数据库、`.env`、TLS 私钥、签名密钥、设备数据、缓存和 `sources/`。Android 可通过系统文件保存器选择备份与源码的保存位置，网页使用浏览器下载。

## 验证方法

```powershell
.\.venv\Scripts\python.exe -m pytest -q -W error
npm test
# 单独启动隔离数据库的模拟服务后，运行浏览器验收。
.\.venv\Scripts\python.exe -m uvicorn tests.browser_server:app --port 8011
node tests/browser.mjs
```

浏览器验收默认启动独立无窗口 Edge，不使用个人浏览器数据；可用 `T_BROWSER_CHANNEL=chrome` 选择 Chrome，或 `T_BROWSER_CDP` 指定已有调试实例。覆盖 600 条历史、像素偏移保持、发送和重试、离线多条消息保留与重连、草稿、角色创建、设置更新、搜索与日历跳转及桌面/手机截图。模型 API 测试完全模拟，不产生付费请求。设置中的“测试已保存连接”会产生一次极短的真实模型请求，供使用者配置后验收。

本轮不实现长期记忆、自主生活、后台主动聊天、推送或世界系统；界面只显示同步、发送、生成和失败状态。
