# 世界摇杆 · 0.12.1

从干净的 `feat/resident-life-sharing@c5b45f1` 创建 `feat/world-joystick`。保留暖木房间和已有居民生活，只增加控制方式。

## 使用

世界 → 左下圆形摇杆，按住拖向上下左右持续走，松手停下。拖回中心暂停；斜拖按偏移较大的方向走，避免穿过家具角落。默认控制“我”，仍可在“移动对象”选择居民。墙、家具、其他人物会挡路。点击地板寻路、点击人物交谈和地点交互继续可用。

“世界经历与知情范围”是来源记录：保存实际发生的事及有依据知情的人，供召回、分享和来源核对。它默认折叠；“保存为某人的经历”是人工记忆入口，自动整理设置见居民生活。移动不会自动改写名册或把所有事件变成长期记忆。

## 数据与复用

- `world-joystick.js` 是本项目新增的输入控制代码，AGPL-3.0-only，无新增依赖或外部素材。
- 继续复用本项目 `world-map` 的碰撞、`world-ui` 的命令/动画、`WorldModule` 与统一写入事务；寻路仍为已记录来源的 Alicization Town 适配，不重新导入上游文件。
- 输入只提出一格移动；程序校验后保存位置、事件和实际观察者。一次只执行一个保存，两次提交至少间隔 180ms；保存较慢时等它完成再提出下一步，不额外等待或积压队列。撞到障碍不提交命令；保存失败停止，重试沿用失败请求标识。
- 松手不能撤销已经提交的一步，但不再发下一步。指针取消、失去捕获、窗口失焦、页面隐藏及退出世界都会停止；计时器由输入控制器拥有。
- 按住时只读取最新世界并绘制，松手后更新经历列表；人物、模型、记忆、后台调度和数据库格式不变。
