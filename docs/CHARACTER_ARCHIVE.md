# 人物图片档案（0.17.0）

桌面打开「档案」，选择人物，在「相册」上传 PNG、JPEG 或 WebP。点击图片可命名、选择皮肤、绑定内置表情或添加命名表情；「表情」分页按皮肤列出已经配置的图片。「皮肤与动作」打开原衣橱，继续编辑小人行走、皮肤和交互动画。衣橱的表情页也能从此人物档案选择图片。

图片名称与表情名称分开。例如相册图片名为「窗边的笑容」，绑定表情名为「得意」；人物输出已有的 `[情绪:表情ID]` 后，世界对话框读取相同图片。重命名自定义表情不改变其 ID。普通线上聊天的 emoji、原有场景流式对话和模型配置保持原行为。

本阶段支持本机浏览器与独立 Android。共同后端显示本机模式提示；没有另建服务器数据库。图片生成、模型主动调用生图工具和聊天图片附件留待后续；本版上传不会请求模型。图片不是世界事件或记忆证据，不会修改 Canon/Persona。

## 数据与写入

- `character_archive: {version:1, items:[...]}` 属于图片档案。每项包含稳定 ID、所属人物、图片名、图片、归档时间和来源；当前来源是上传（保留文件名）或从人物形象导入。归档时间不冒充原图片生成时间。当前最多 200 项，图片经原上传规则缩至最长边 768 像素，编码上限 1,200,000 字符。
- `CharacterArchiveModule` 通过 `/character-archive/{owner}` GET/POST 和 `/{asset}` PATCH/DELETE 管理目录。上传调用者生成请求 ID，保存失败复用该 ID 重试；相同 ID、归属、图片和原始文件名返回原记录，冲突拒绝。名称、所有者、来源和数据格式统一校验。
- `CharacterLooksModule` 保有皮肤和表情绑定。`/character-looks/{owner}/archive-binding` POST 接受本人的图片 ID、皮肤、表情及预期旧图片 ID；DELETE 解除该图片的表情使用。已有表情被其他操作替换后，过时写入明确拒绝。同一人物可在多个皮肤复用图片，不能引用其他人物的档案。
- 旧 `portraits[].image` 保留为兼容投影，并增加 `asset_id`。世界、无界面居民规则及旧形象编辑继续使用原图片形状。首次读取档案在原事务中补齐目录与引用；已有绑定、当前皮肤、像素图、身份及记忆不变。随后从旧衣橱上传的立绘也经同一归档入口补齐引用。不会迁移行走帧为相册图片。
- Android `TLookAssets` 同时遍历档案和旧形象投影，把图片内容去重存入原 `look_assets` 表；文档中存引用，读取时恢复兼容形状。相册独有图片仍被保留，最后一个引用删除才回收字节。没有新增数据库版本或第二套图片缓存。
- 浏览器继续使用原 IndexedDB 业务文档。备份保留目录和绑定，恢复校验丢失图片、跨人物引用及图片内容不匹配。存储失败回滚整份候选。原生前后台仍共用原事务、CAS 和租约；后台规则保留档案字段。

正在使用的图片不能直接删除。先在图片详情「解除使用」，再删除；从衣橱删除皮肤或表情只解除使用，相册图片保留。此操作不删除聊天、世界事件或记忆。历史对话沿用现有按皮肤当前表情找图的规则，尚未冻结每条历史台词的图片版本。

## 界面与复用

档案沿用小手机的颜色与字体，人物选择和三个分页固定在顶部，内容独立滚动。图片详情固定关闭按钮，图片完整显示、不裁去面部，正文可以滚动。文件读取沿用浏览器/Android 文档适配，读取期间检查人物和页面是否改变。

复用本仓库基线 `8421105e311a945a558ee1fac40056c5abc76c96` 的 `frontend/character-image-input.js`（原生选择与取消）、`character-looks.js`（皮肤、表情与验证）、`character-looks-ui.js`（原衣橱）、`world-art.js` 与 `world-dialogue-ui.js`（场景图片）、`local-service.js`（统一事务、备份）、`TLookAssets.java`（SQLite 内容去重）。原立绘读取逻辑集中为 `readCharacterPicture`，供衣橱和档案共用；档案本身不组装模型上下文。

已核对既有参考清单和来源记录。参考项目的在线账号、媒体库或 Node 世界服务器不适合直接替代本项目的本机事务与 SQLite 图片存储。本次为现有接口增加目录和绑定，没有导入外部源文件或素材；新增代码沿用本仓库 AGPL-3.0-only。测试图片由 Canvas 合成，不提交私人截图。

## 验证入口

- `tests/character-archive.test.mjs`：幂等、并发、人物隔离、旧图片归档、稳定表情 ID、过时绑定、删除保护、失败回滚、备份与不泄露图片到文字上下文。
- `tests/character-archive-browser.mjs`：手机尺寸上传和命名、自定义表情、分页、失败重试、固定关闭、世界实际换图、旧衣橱选择、重启和备份；仅模拟模型。
- `CharacterArchiveInstrumentation.java`：原生 SQLite 图片去重、归档独有图片保留、投影读写及无引用回收。
- `tests/character-archive-android.mjs`：专用 Android 模拟器的原生触屏、系统选图、SQLite 与重启；结合原升级脚本验证 code24→25 数据保留。

验证结果和公开试用安装包在发布验收后记录。
