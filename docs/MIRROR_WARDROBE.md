# 镜子衣柜与人物适配（0.23.0）

世界 → 头像菜单 → 衣柜。中央镜子显示当前人物，两侧选择头发、帽子、配饰、上衣、下装、鞋子；下方公共衣物列表点选即可穿上。转身或播放行走检查效果，最后「穿好并应用到世界」。关闭与应用固定在窗口两端，内容独立滚动。

「整套搭配」保存当前衣物组合，其他人物可以直接试穿；只保存公共衣物的 ID，不复制图像或人物身体。切换人物保留同一个公共衣柜，每个人恢复自己的适配。

## 原版与个人适配

- 公共原版在标准身体坐标制作，保存一份共享工程。
- 穿上时建立人物 × 衣物的适配记录：引用原版版本、大小和位置。单纯试穿不复制像素工程。
- 「调整我的穿着」里修改位置，或「绘制这个人物的适配」。绘画复用原方格编辑器，有草稿、撤销、细化、缩放和平移；保存的像素只属于此人物，不覆盖公共原版。
- 脱下仅取消当前穿戴，保留适配；再次穿回或通过套装穿回时恢复。
- 「制作 / 管理衣物」才显示创建、上传、公共原版绘画、另存和删除。本体仍可在这个制作入口上传、绘画、更换和调节身高。
- 原版更新时，仍被引用的旧版保存一次，各人物继续使用旧版及自己的绘画。「使用最新版重新适配」需要确认，会清除此人物对该衣物的草稿、绘画和位置，再从新版开始。
- 不允许删除正在穿戴、作为本体或被搭配引用的素材。未穿戴但有适配的素材，删除时明确确认并清除对应适配。

## 责任与兼容

`outfit-adaptation.js` 负责原版解析、个人适配和穿回规则；`outfit-catalog.js` 负责目录校验、原版历史、搭配及统一写入。`outfit-compose.js` 与世界应用入口均读取解析后的有效衣物，不能绕过人物适配使用最新原版。

界面只经原 `/character-looks/user/workshop` GET/PUT、`workshop-apply` POST 保存。原事务队列、SQLite CAS、写入租约、备份及图片去重继续使用。新增可选字段：素材 `editions`、人物 `adaptations`、目录 `sets` 与最后一次操作回执 `last_operation`；旧目录无需迁移。更新后的备份包含新字段，需要 0.23.0 或更新版本读取。

原版历史不可通过普通写入改写；只有仍被人物引用的版本保留。像素修改才创建个人工程；缩放、位移只保存数值。套装不带人物专属位置。PUT 可带唯一 `request_id`，最近成功操作的同 ID/基础版本重试返回已保存结果；其他过期写入仍冲突。保存失败不改变成功状态。

本机浏览器和 Android 共用规则与渲染。可选 Python 共同后端没有新增衣柜服务；本轮验收范围是本机模式。64×96 与精细 128×192 绘画保留；复杂衣物遮挡和额外交互动作仍沿用已有边界。

## 复用

继续使用项目已有绘画台、PaintSession、Piskel 连通填色适配、部位动作模板、Canvas 合成及持久化接口，没有增加第三方代码或依赖。逐文件上游版本/许可见 `config/outfit-workshop-sources.json` 与原 `docs/MODULAR_OUTFITS.md`；供应商文件未修改。用户提供的镜子截图只参考布局，不导入游戏素材、图标或配色资源。新界面沿用 T- 的木框与原画布。
